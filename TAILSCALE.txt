TAILSCALE

selecione as VPS-21 e VPS-2, execute o comando (irá instalar o tailscale)
-->  curl -fsSL https://tailscale.com/install.sh | sh

Ativar o tailscale nas vps
--> sudo tailscale up

Para cada vps será gerada ums URL de acesso, cadastre as informações
--> ambas as vps estão logadas na rede tailscale


Após execute --> tailscale status
irá mostrar os ips das vps, ex.:

root@vps1:~# tailscale status
100.103.148.101  vps1  App-Legal@  linux  -
100.122.196.23   vps2  App-Legal@  linux  -
root@vps1:~#
